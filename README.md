# موقع السيفي - Essam Hamood Abdo

موقع سيرة ذاتية/بورتفوليو جاهز للرفع على GitHub Pages.

## الملفات الأساسية
- `index.html`
- `styles.css`
- `script.js`
- `cv.html`
- `assets/`

## المعاينة المحلية
افتح `index.html` مباشرة أو ارفع المشروع على GitHub Pages.

## النشر على GitHub Pages
1. ارفع ملفات المشروع إلى مستودع GitHub.
2. ادخل إلى **Settings > Pages**.
3. اختر الفرع الذي رفعت عليه الملفات.
4. اجعل النشر من **/(root)**.
5. احفظ الإعدادات.

## ملاحظات
- زر تحميل السيرة الذاتية مرتبط بملف PDF داخل `assets`.
- الموقع يدعم اللغة العربية والإنجليزية والوضع الليلي/النهاري.
